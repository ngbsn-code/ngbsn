# NGBSN Emulator — actualizaciones

Carpeta `update/`: actualizaciones del motor de NGBSN Emulator. El emulador descarga `update/manifest.json`, comprueba
el tamaño y el SHA-256 de cada archivo y solo entonces usa la versión nueva. Las actualizaciones nunca tocan las
partidas (Memory Cards). No contiene ROMs ni juegos.
